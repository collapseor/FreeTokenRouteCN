# CodeGeeX

## 基本信息

- **厂商**：智谱 AI (Zhipu AI)
- **官网**：https://codegeex.cn/
- **注册地址**：https://codegeex.cn/
- **模型类型**：开源免费

## 免费额度

- 开源模型，可本地部署或使用在线服务
- 在线服务有免费额度

## 模型列表

## API 接入方式

### 方式一：本地部署

```bash
# 使用 transformers 或 vLLM 本地部署
# 完全免费，需要 GPU
```

### 方式二：在线 API

```bash
# API Base: https://open.bigmodel.cn/api/paas/v4/
# 需要 API Key，有免费额度
```

## 注册步骤

1. 访问 https://open.bigmodel.cn/
2. 注册智谱 AI 账号
3. 创建应用获取 API Key
4. 即可使用 CodeGeeX API

## 限制说明

- 免费额度有限
- 本地部署需要一定硬件资源
