# 讯飞星火认知

## 基本信息

- **厂商**：科大讯飞 (iFLYTEK)

- **官网**：<https://xinghuo.xfyun.cn/>

- **注册地址**：<https://xinghuo.xfyun.cn/>

- **模型类型**：免费

## 免费额度

- 星火认知大模型提供免费试用额度

- 新用户注册可获得免费 token

## 模型列表

| 模型 ID      | 名称      | 上下文长度 | 说明  |
| ---------- | ------- | ----- | --- |
| spark-lite | 星火 Lite | -     | 轻量版 |
| spark-pro  | 星火 Pro  | -     | 专业版 |
| spark-max  | 星火 Max  | -     | 旗舰版 |

## API 接入方式

### 官方 API

```bash
# API Base: https://spark-api.xf-yun.com/v1.1/chat
# 需要申请 API Key
```

## 注册步骤

1. 访问 <https://xinghuo.xfyun.cn/>
2. 注册讯飞账号
3. 创建应用获取 API Key
4. 开通星火认知大模型服务

## 限制说明

- 免费额度有限，超出需付费

- 不同模型版本额度不同
