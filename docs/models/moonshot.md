# 月之暗面 - Kimi

## 基本信息

- **厂商**：月之暗面 (Moonshot AI)
- **官网**：https://kimi.moonshot.cn/
- **注册地址**：https://kimi.moonshot.cn/
- **模型类型**：免费

## 免费额度

- Kimi Chat 免费使用
- 支持长上下文对话

## 模型列表

| 模型 ID | 名称 | 上下文长度 | 说明 |
|---------|------|-----------|------|
| moonshot-v1-8k | Kimi 8k | 8K | 基础模型 |
| moonshot-v1-32k | Kimi 32k | 32K | 长上下文 |

1. 访问 https://kimi.moonshot.cn/
2. 使用手机号注册账号
3. 完成实名认证（如需要）
4. 即可免费使用 Kimi Chat
