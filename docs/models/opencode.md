# OpenCode

## 基本信息

- **类型**：开源代码模型

- **官网**：<https://github.com/opencode-ai/opencode>

- **注册地址**：无需注册，开源使用

- **模型类型**：开源免费

## 免费额度

- 完全开源，可免费本地部署

- 无需 API Key，本地运行无限制

## 模型列表

## API 接入方式

### 本地部署

```bash
# 克隆仓库并本地部署
git clone https://github.com/opencode-ai/opencode.git
cd opencode
# 按照文档配置本地部署
```

### 使用 OpenAI 兼容接口

```bash
# 本地部署后可暴露 OpenAI 兼容接口
# Base URL: http://localhost:8000/v1
```

## 使用步骤

1. 克隆开源仓库
2. 按照文档配置环境
3. 下载模型权重
4. 启动本地服务

## 限制说明

- 完全免费，但需要本地硬件资源（GPU）

- 部署复杂度取决于模型大小
